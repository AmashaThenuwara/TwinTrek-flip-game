TwinTrek FLIP Game 🚀

User Manual & Setup Guide

1. Database Setup (MySQL) 🗄️

The application is configured to use a MySQL database. Follow these steps before running the backend:

  1. Make sure you have MySQL Server installed and running (e.g., via XAMPP, WAMP, or MySQL Workbench).
  2. Open MySQL and create a new database by running:
    CREATE DATABASE twintrek_db;
  3. Alternatively, you can just run the database_setup.sql file provided in the TwinTrek_FLIP_Game folder.
  4. Important: The application expects your MySQL username to be root and the password to be left blank (empty). If yours is different, edit these values in src/main/resources/application.properties.
Note: You DO NOT need to create any tables manually! Spring Boot and Hibernate will automatically generate all the necessary tables (player, game_session, etc.) when the backend server starts.

2. Running the Backend Server ☕

The backend powers the authentication, database storage, and game logic.

  1. Open a terminal (Command Prompt or PowerShell) inside the inner TwinTrek_FLIP_Game\TwinTrek_FLIP_Game folder (where the pom.xml is located).
  2. Run the following script to safely start the Spring Boot server (this will automatically clean up any stuck ports!): 
    .\start-server.bat
  3. Wait until you see Started TwinTrekFlipGameApplication. The server is now running on port 8080.

3. Running the Frontend Server ⚛️

The frontend provides the beautiful UI and game screens.

  1. Open a second, separate terminal and navigate into the frontend folder: 
    cd flip-game-frontend
  2. Install dependencies (you only need to do this once): 
    npm install
  3. Start the development server: 
    npm run dev
  4. Your browser should automatically open, or you can go to http://localhost:5173.

4. How to Play the Game 🎮

Welcome to TwinTrek! Your goal is to find all the matching animal pairs as fast as you can. Here is how it works:

  1. Create an Account: Register a new player account and log in.
  2. Explore the Menu: On the main menu, you can click the F (Figures) tile to view the global Leaderboard, or the I (Instructions) tile to read detailed rules on dedicated full-screen pages.
  3. Choose Difficulty: Click the L (Level) tile to select between Easy, Medium, or Hard, then click PLAY NOW to start!
  4. Flip the Cards: Click on any two cards to flip them over. If the animals match, they stay face-up!
  5. Memorize: If the cards don't match, they will flip back over. Try to remember their positions!
  6. Score Points: You earn points for finding matches. You earn a Combo Bonus if you find multiple matches in a row without making a mistake!
  7. Game Controls: During a game, if you want to completely restart the current round instantly, click the 🔄 Refresh button on the left panel (or bottom on mobile). To exit your game and return to the main menu, click the 🔙 Menu button located in the top-left corner.
  8. Compete: Complete the board as fast as you can with the fewest moves to climb the Global Leaderboard!
