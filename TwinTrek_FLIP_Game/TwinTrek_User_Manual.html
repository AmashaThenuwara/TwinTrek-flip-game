TwinTrek FLIP Game 🚀

User Manual & Setup Guide

1. Database Setup (MySQL) 🗄️

The application is configured to use a MySQL database. Follow these steps before running the backend:

  1. Make sure you have MySQL Server installed and running (e.g., via XAMPP, WAMP, or MySQL Workbench).
  2. Open MySQL and create a new database by running:
    CREATE DATABASE twintrek_db;
  3. Alternatively, you can just run the database_setup.sql file provided in the TwinTrek_FLIP_Game folder.
  4. Important: The application expects your MySQL username to be root and the password to be left blank (empty). If yours is different, edit these values in src/main/resources/application.properties.
Note: You DO NOT need to create any tables manually! Spring Boot and Hibernate will automatically generate all the necessary tables (player, game_session, etc.) when the backend server starts.

2. Running the Backend Server ☕

The backend powers the authentication, database storage, and game logic.

  1. Open a terminal (Command Prompt or PowerShell) inside the inner TwinTrek_FLIP_Game\TwinTrek_FLIP_Game folder (where the pom.xml is located).
  2. Run the following command to start the Spring Boot server: 
    .\mvnw spring-boot:run
  3. Wait until you see Started TwinTrekFlipGameApplication. The server is now running on port 8080.

3. Running the Frontend Server ⚛️

The frontend provides the beautiful UI and game screens.

  1. Open a second, separate terminal and navigate into the frontend folder: 
    cd flip-game-frontend
  2. Install dependencies (you only need to do this once): 
    npm install
  3. Start the development server: 
    npm run dev
  4. Your browser should automatically open, or you can go to http://localhost:5173.

4. How to Share This Application with Users 🌍

If you want other people to play your game, you have a few options depending on what you want to achieve:

Option A: Sharing via Local Network (Wi-Fi) 🏠

If your friends are on the same Wi-Fi network as you:

  1. Find your computer's local IP address (open Command Prompt and type ipconfig, look for IPv4 Address, e.g., 192.168.1.5).
  2. Start the frontend with the host flag: npm run dev -- --host
  3. Tell your friends to open their browser on their phone or laptop and go to: http://YOUR_IP_ADDRESS:5173

Option B: Sharing the Source Code 📂

If you want to send the project to another developer or a teacher:

  1. Delete the node_modules folder inside flip-game-frontend to save space.
  2. Delete the target folder in the main directory.
  3. Zip the entire TwinTrek_FLIP_Game folder and send it to them.
  4. They can follow steps 1-3 in this manual to run it on their machine!

Option C: Publishing to the Internet (Hosting) ☁️

If you want anyone in the world to access it via a link (e.g., twintrek-game.com), you need to host it:

  • Frontend: Build the frontend using npm run build and host the dist folder for free on Vercel, Netlify, or GitHub Pages.
  • Backend & Database: Host your Spring Boot backend on Render.com, Railway.app, or Heroku. You will also need to provision a cloud MySQL database (like Aiven or PlanetScale) and update your application.properties with the cloud database credentials.
